# Manual de instruções

## Objetivo

Criar uma recomendação arquitetural contextual, com módulos, versões e trade-offs explícitos.

## Uso

Abra **Criar arquitetura**, escolha o tipo de produto e as tecnologias, e gere o resultado. Clique em um nó do diagrama para entender sua responsabilidade. Copie a árvore de diretórios como referência inicial.

## Desenvolvimento

Execute `npm install`, `npm run dev`, `npm run test` e `npm run build`. Para acrescentar uma regra, altere o catálogo e o motor de recomendação, escreva um teste unitário do motor e atualize `docs/versions.md` se a compatibilidade mudar.
